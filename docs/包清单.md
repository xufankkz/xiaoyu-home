# 软件包与组件包清单

版本 0.2.0-beta.2，Windows x64。两包独立安装；先装软件，按用途选择组件。文件大小和 SHA-256 见同目录的交付清单，不以源码或开发环境目录大小代替下载大小。

| 包 | 随包内容 | 用途 |
| --- | --- | --- |
| 软件包 | 小鱼之家桌面启动器，共用网页/Qt界面，Python、Qt WebEngine、Node运行时；大肥鱼人格/记忆/情绪/学习/日记核心；QQ桥接与MCP工具；空间、日记、表情、媒体服务；本地聊天、模型配置、预算账本；加密迁入导出工具；许可、源码与构建说明 | 首次打开为空白角色；提供主体功能与外部接入入口 |
| 组件包：DSH（可选） | 独立 DeepSeek Harness 0.2.1-rc.3 官方npm运行环境及依赖、组件清单和原许可 | QQ多轮会话和角色工具宿主；采用本实例模型网关；本地聊天不必安装 |
| 组件包：离线翻译（可选） | 独立翻译程序、CTranslate2/SentencePiece运行库、OPUS en→zh1.9公共模型、原始模型说明及许可 | 将已保存的英文思考展示为中文；在本机CPU运行 |

## 软件提供的功能模块

- 入住与模型、本地聊天、迁入与备份、接入与组件、模型与费用五个发行专用入口。
- 首页、思考、人设、语音、联系人、空间、抖音、记忆、学习、日记、情绪、花费、碎碎念、拒绝权、QQ接入和设置；网页与桌面加载同一套页面和接口。
- 记忆分层、搜索、星图、更正/保留原文、关系状态；四套外观、显示模式及三套夜间强调色。
- OneBot正向WS客户端；私聊/群白名单、原内容跨会话分享、逐目标送达/去重及收图记忆归属的实现保留。空间、戳一戳、资料修改、媒体等扩展依赖所选连接端，不能由标准连接成功推定全部可用。
- 手动导入PNG/JPEG/GIF/WebP表情图片，每张最多8MiB；原图保存、哈希去重、默认按文件名检索。语义标注使用另外配置的图片理解模型并计入估算预算。
- 语音支持GPT-SoVITS /tts与OpenAI兼容/audio/speech，转写支持/audio/transcriptions，绘画支持/images/generations；不把任意API地址视作协议兼容。

## 使用者另行准备

| 用途 | 另行提供 |
| --- | --- |
| 聊天、总结和学习 | 自己的OpenAI兼容聊天服务/API Key/模型、单价与预算；软件不含大语言模型权重 |
| QQ | 自行安装并登录获准使用的OneBot v11连接端，填写HTTP/正向WS及令牌、账号与白名单；本包不分发QQ、网关或SnowLuma专属组件 |
| 语音 | 自己的TTS服务、获准使用的音色模型与参考音频，或兼容语音API |
| 语音转写/视频 | 自己的ASR API、本机FFmpeg/ffprobe；视频按至多8帧和音轨抽样分析，支持至多5分钟/64MB，并非逐帧完整观看 |
| 图片理解/绘画 | 支持对应协议的模型、Key及单价 |
| 表情/角色立绘 | 自己有权使用的图片；不含发布者素材 |
| 抖音桌面 | Windows中文OCR组件、已登录的唯一可见抖音窗口、自有模型及账户配置；发评论/@的截图绑定与编辑器模板尚需用户自己校准，未建立全自动首次校准向导 |

## 本测试版限制

新机真实QQ、各第三方连接端扩展、用户所选模型/音色、抖音真实发布均须在使用者自己的环境逐项验收；此发行验证使用本地模拟，不代替真实服务验收。迁入支持范围另见迁入兼容范围。暂不提供自动更新、自动诊断上传、多角色同时运行或任意插件完整迁移承诺。

软件与公共组件免费非商业发行，外部模型/API可能收费。安装默认不连接外部账号、不启用后台任务。安装包不包含发布者个人数据、合成测试记录、验证截图、日志、备份、构建虚拟环境或Git登录信息。
