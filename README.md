# 小鱼之家 · 测试发行版

版本：0.2.0-beta.1。Windows x64 非商业测试发行版，包含角色、记忆、情绪核心和共用网页/桌面界面，以及独立本地聊天、接入配置和迁入工具。首次安装为空白实例，角色、模型、联系人、素材由使用者设置。

## 安装和开始使用

1. 安装 `XiaoyuHome-0.2.0-beta.1-Windows-x64-Setup.exe`，从桌面“小鱼之家·测试发行版”打开。内含 Python、Qt WebEngine 和 Node 运行时，无需自行安装 Python/Node。
2. 在“入住与模型”填写角色名字、称呼、人设、API 根地址、模型名、Key、单价和每日预算。也可先在“迁入与备份”查看支持的文件格式和差异计划。
3. 使用“聊天”进行本地对话。不接 QQ 也能使用本地聊天、人格和记忆功能；模型由你提供，外部模型可能收费。
4. 按需安装组件包，再到“接入与组件”启用独立 DSH、配置自己的 OneBot v11 HTTP/正向 WS、账号和白名单。空白名单不放行联系人。
5. 语音、语音转写和绘画分别配置兼容协议。表情图片在“接入与组件”导入。视频/语音解码需自行提供含 ffmpeg.exe/ffprobe.exe 的 FFmpeg bin 文件夹。

程序按需分配本机端口，不要求固定盘符。软件目录默认 `%LOCALAPPDATA%\Programs\XiaoyuHomeBeta`，用户资料默认 `%LOCALAPPDATA%\XiaoyuHome`，组件默认其下的 `components`。关闭本实例窗口时退出它拥有的后台进程；不会按端口或程序名停止其他安装。卸载保留用户资料，重新安装不会清空角色。

## 软件包 / 组件包

具体内容、依赖与边界见 [包清单](docs/包清单.md) 和 [迁入兼容范围](docs/迁入兼容范围.md)。软件包含完整功能模块，但外部账号、模型和连接端不随包配置；支持标准协议不表示任意连接端都支持空间、戳一戳等所有扩展。状态页的端口可达也不等于端到端业务验收。

## 数据、费用与活动

- 不包含发布者的人设、聊天、记忆、账号、API Key、联系人、图片、音色或参考音频。
- Key 与连接令牌由 Windows DPAPI 加密绑定当前 Windows 账号；聊天与记忆数据库仍是本机普通文件。加密迁移包不携带凭据；换电脑后重新填写 Key。
- 调用模型时，你的消息、角色人设和所选记忆会发送到你配置的服务商；TTS 发送待合成文字，ASR 发送待转写音频，看图发送选定图片/抽样画面。网页检索会向搜索服务发送查询词。不是全离线软件。
- 初始关闭 QQ 连接、语音服务和自动任务。启用后台活动前检查学习/日记/联系等细项、联系人和预算。避免同一 QQ 同时运行新旧回复链路。
- 模型预算根据你填写的价格和本地预留估算；不能代替服务商账单或服务商侧限额。远程服务价格填 0 会按零费用估算。结果不明的已发送请求保留预留额度，不自动重发。
- 不自动上传诊断，不自动下载安装更新。此版本安装程序未作发行者代码签名；请核对来源与 SHA-256。
